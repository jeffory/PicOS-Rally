# PicOS Rally

A top-down arcade-sim rally game (Art of Rally presentation) for the
[ClockworkPi PicoCalc v2.0](https://www.clockworkpi.com/) handheld, running on
[PicOS](https://github.com/jeffory/PicOS). Native C app: one finished stage —
**Cooloola Point**, ~2.7 km of Queensland coastal gravel: sugarcane sweepers,
a bitumen township chicane, paperbark esses with two hairpins, a creek
splash, a headland crest-jump, and a beach-flat finish.

Deterministic 60 Hz bicycle-model physics with per-surface grip, baked
racing line + pacenotes + checkpoints, a pursuit-AI shakedown driver,
palette-locked pixel art (PixelLab + custom bake pipeline), tile renderer
with dust/skids, and a Core-1 synth audio mix (engine, surface noise,
pacenote/result stingers).

## Build

Requires `arm-none-eabi-gcc` and the PicOS SDK headers (vendored at
`sdk/native/` — pinned copy; sync from PicOS upstream when the ABI changes).

```bash
make            # produces main.elf
```

## Dev loop

- `plat/headless/` — host test runner (`make && ./rally_headless`, TAP
  output; physics, completability AI, tilemap, gfx, audio, effects) and
  `scene.c` (render any stage distance to a PPM for eyeballing).
- `tools/trackbake.py` — stage TOML → `stage01.bin` (racing line, target
  speeds, pacenotes, checkpoints, surface grid, wang tilemap, prop scatter).
- `tools/tilebake.py`, `spritebake.py`, `palettize.py`, `procgen_road.py` —
  art pipeline: PixelLab PNGs (`art/`) → palette-locked 8bpp bins
  (`assets/`). Palette source of truth: `art/style.toml`.
- `tools/rally_hw.py` — serial driver for hardware: zip+push, launch,
  keypresses, screenshots (env `RALLY_APP_DIR` overrides the app dir).

## Layout

- `app/` — PicOS API glue (main loop, race flow, asset loading, audio worker)
- `core/` — platform-free game code (sim, camera, track, ai, gfx, effects,
  audio_synth, renderers); also builds for the host test runner
- `assets/` — baked 8bpp art the game loads (generated by `tools/`)
- `art/` — source art: style.toml palette, PixelLab PNGs, bake key maps
- `tracks/` — stage definitions (TOML centreline + scenery)
- `tuning/` — handling constants (hot-reloadable on device with 'r')
- `sdk/native/` — vendored PicOS native-app ABI (from the PicOS repo)
- `NOTES.md` — the running engineering log (M0-M5: measurements, decisions,
  tuning, hardware findings)
